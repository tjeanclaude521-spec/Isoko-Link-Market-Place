# Isoko Link – Digital Marketplace for Gisagara District

## About the Project

Isoko Link is a digital marketplace designed to connect farmers, buyers, and other businesses in Gisagara District, Rwanda.

The platform helps local sellers showcase their products online and enables customers to discover products and contact sellers directly.

## Main Features

- Product listings and browsing.
- Farmer-first marketplace.
- Support for other local businesses.
- Direct communication between buyers and sellers.
- Seller contact information.
- English and Kinyarwanda language support.
- Mobile-friendly and low-bandwidth design.
- AI-powered keyword assistance.

## Target Market

Gisagara District, Southern Province, Rwanda.

## Technology Stack

- React
- TypeScript
- Tailwind CSS
- Supabase

## Project Goal

To improve market access for local farmers and businesses, make product discovery easier, and support digital commerce in Gisagara District.

## Development Status

The platform is under development.

## Security

Sensitive credentials, API secrets, and environment variables must never be committed to this repository.
